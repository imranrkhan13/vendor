# Vendor Risk Assessment Agent

Hackathon-ready web agent for the Vultr track. It ingests a SOC2 Type II PDF, a completed
security questionnaire (JSON/CSV), and optional breach context, then produces a structured
risk brief with citations and deterministic confidence/risk scoring.

## Architecture

- `/parser` - SOC2 PDF parsing and questionnaire JSON/CSV normalization
- `/frameworks` - SOC2, ISO 27001, and GDPR control registry
- `/agent` - planning, two-pass retrieval, breach-history tool call, reasoning, and output
- `/scoring` - deterministic scoring and gap-detection rules
- `/api` - FastAPI upload endpoints
- `/frontend` - Next.js demo UI

## Agent workflow

1. Ingest SOC2 PDF and questionnaire.
2. Plan applicable frameworks and control categories.
3. Retrieve SOC2 control descriptions, test results, and auditor opinion.
4. Retrieve questionnaire answers and cross-reference against SOC2 evidence.
5. Query mocked breach history.
6. Apply deterministic scoring and discrepancy rules.
7. Generate a structured risk brief with per-control citations, gaps, follow-ups, and confidence.

The Vultr Serverless Inference adapter is in `agent/vultr_client.py` and uses the
`VultronRetriever` model when `VULTR_API_KEY` and `VULTR_INFERENCE_ENDPOINT` are configured.
Risk scores are never generated by the LLM.

## Run backend

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn api.main:app --reload
```

## Run frontend

```bash
cd frontend
npm install
npm run dev
```

Set `NEXT_PUBLIC_API_BASE_URL` if the API is not running at `http://localhost:8000`.

## Tests

```bash
pytest
```
